# Salisa 'Asyarina Ramadhani · Frontend Developer Portfolio

This repository contains a single-page portfolio site built with Bootstrap 5, jQuery, and custom styling. It highlights Salisa 'Asyarina Ramadhani's background, skills, selected projects, and contact information.

## Getting started

Open `index.html` directly in your browser or serve the project with any static web server. All assets are loaded from CDNs or local directories.

```bash
# Example using Python
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Features

- Hero section with quick call-to-action buttons and an audio introduction
- About section featuring a video demo embed
- Responsive skills grid and project cards
- Bootstrap modal that displays richer project details populated via JavaScript
- Contact form with client-side validation feedback
- Light/Dark theme toggle with persistence using `localStorage`

## Assets

Placeholder files are expected for the media and image references:

- `assets/images/profile.jpg`
- `assets/images/project1.jpg`
- `assets/images/project2.jpg`
- `assets/images/project3.jpg`
- `assets/media/intro.mp3`
- `assets/media/demo.mp4`

Add your own media to these paths or update the HTML references accordingly.
